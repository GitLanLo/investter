# Руководство пользователя (User Manual)

Информационная система анализа рынка ценных бумаг.

## 1. Регистрация и Вход

1. Откройте приложение в браузере (по умолчанию `http://localhost:5173`).
2. Перейдите на страницу **Register**, если у вас еще нет аккаунта.
3. Введите Email и пароль для регистрации.
4. После регистрации войдите в систему на странице **Login**.

## 2. Настройка интеграции с Tinkoff

Для получения актуальных рыночных данных необходимо подключить персональный токен Tinkoff Invest API:

1. Перейдите в раздел **API Settings** (кнопка в навигации).
2. Введите ваш API Token (получить его можно в личном кабинете Тинькофф Инвестиции в разделе настроек).
3. Нажмите **Test Connection**, чтобы убедиться в правильности токена.
4. Нажмите **Save Token**. Токен будет зашифрован и сохранен в базе данных.

## 3. Управление списком наблюдения (Watchlist)

1. На главной странице (**Watchlist**) воспользуйтесь строкой поиска в верхней части экрана.
2. Введите тикер (например, `SBER`) или название компании.
3. В результатах поиска нажмите **Add**, чтобы добавить инструмент в ваш список наблюдения.
4. Вы можете удалить инструменты из списка, нажав кнопку **Remove** в таблице.

## 4. Анализ инструмента

1. В таблице Watchlist нажмите на тикер инструмента, чтобы перейти на его детальную страницу.
2. На детальной странице вы увидите:
   - **Интерактивный график**: японские свечи и технические индикаторы (EMA 20, EMA 50).
   - **Действия**:
     - **Refresh Data**: принудительное обновление свечей через Tinkoff API.
     - **Run Analysis**: запуск ML-модели для генерации сигнала по актуальным данным.
   - **Latest Signals**: таблицу последних сгенерированных сигналов с указанием направления (UP/DOWN/NONE) и вероятности.

## 5. Настройка уведомлений (Alerts)

1. Перейдите в раздел **Alerts** через навигационное меню.
2. В секции **Notification Rules** вы можете создать правило:
   - Укажите тикер (или оставьте пустым для всех инструментов).
   - Выберите тип события (например, "Confidence Trigger" для сигналов с высокой вероятностью).
   - Выберите направление и порог вероятности (например, 0.85 для 85%).
3. В секции **Alert History** вы увидите список всех сработавших уведомлений.

## 6. Панель администратора (Admin ML)

*Примечание: В текущей версии доступна всем авторизованным пользователям.*

1. Перейдите в раздел **Admin ML**.
2. Здесь вы можете:
   - Видеть статус здоровья системы (System Monitoring).
   - Проверять, какая ML-модель сейчас является активной.
   - Отслеживать выполнение фоновых задач по обновлению данных.
   - Просматривать результаты исследований и при необходимости продвигать новые политики валидации (**Promote**).
